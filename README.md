# CRA Standards Progress

> Cite as: CVD Portal, "CRA Standards Progress: the ETSI EN 304 vertical series under standardisation request M/606", 2026-09-01. https://cvdportal.com/research/cra-standards-progress (CC BY 4.0)

Per-deliverable status of the ETSI EN 304 6xx vertical Cyber Resilience Act standards, mapped to every Annex III and Annex IV point, with the ETSI work item reference, the work programme status, the approval-procedure date, the permanent published PDF and the public draft repository. Records the Official Journal citation state for each deliverable, which is what decides presumption of conformity under Article 27.

The page of this dataset is https://cvdportal.com/research/cra-standards-progress. Read the method and the limits there before you use a figure.

## Fields

Top-level fields of `cra-standards-progress.json`:

- `name`
- `description`
- `url`
- `publisher`
- `license`
- `licenseUrl`
- `lastVerified`
- `citation`
- `methodology`
- `summary`
- `deliverables`
- `annexPointsOutsideEtsi`

The `citation` field holds the attribution text. The `methodology` or `source` field, where present, describes how the data was made.
